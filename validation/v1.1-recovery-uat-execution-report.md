### UAT-015B - Injected mid-operation rollback and later success

**Setup and exact injection.** A fresh fixture-09 item was created. The public
workflow dependency was temporarily replaced; the real dependency was restored
unconditionally in `finally`.

```python
real_enter = workflow.enter_fish_result
state = {"calls": 0}

def flaky_enter(*args, **kwargs):
    state["calls"] += 1
    if state["calls"] == 2:
        raise inbound_hl7.InboundError(
            "INVALID_INTERPRETATION",
            "injected handled mid-op failure",
        )
    value = real_enter(*args, **kwargs)
    # Read-only milestone evidence captured here, before call 2.
    return value

workflow.enter_fish_result = flaky_enter
try:
    f = recovery.redrive_queue_item(
        conn, 1, corrected("09_specimen_incompatible.hl7"),
        request_id="REC-UAT15B-MID", actor="analyst01",
    )
finally:
    workflow.enter_fish_result = real_enter
```

**Pre-fault milestone evidence.** `state["calls"] == 2`. After call 1 returned
but before call 2 raised, the still-open transaction contained one
`fish_result`, one `RESULT_ENTERED` event, and `conn.in_transaction is True`.
After the call, `workflow.enter_fish_result is real_enter` was true.

**Rollback evidence.**

| Observation after FAILED attempt | Value |
|---|---|
| attempt | 1, `REDRIVE_CORRECTED / FAILED` |
| attempted message | message 2, `ERRORED` |
| `fish_result` | 0 |
| `RESULT_ENTERED` | 0 |
| `INBOUND_RESULT_FILED` | 0 |
| order before / after | `IN_PROCESS / IN_PROCESS` |
| queue before / after | `OPEN / OPEN`; both timestamps null |
| transaction after handled outcome | `False` |
| dependency restored | `True` |

The first result and event were written inside the open transaction, then rolled
back when call 2 raised. The service separately preserved and committed the
approved ERRORED message plus FAILED attempt and left no dangling transaction.
A new request `REC-UAT15B-OK` then produced SUCCEEDED attempt 2, FILED message
3, and a RESOLVED queue. Exactly one SUCCEEDED attempt existed.

**Comparison:** the injection point, pre-fault writes, rollback, preserved
records, teardown, clean transaction state, and later success all matched the
procedure. **Result: PASS.**
